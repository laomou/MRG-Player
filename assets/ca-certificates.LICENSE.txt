The file ca-certificates.crt is the Mozilla CA root bundle published by the
curl project at https://curl.se/ca/cacert.pem (generated from
https://hg.mozilla.org/mozilla-central/raw-file/tip/security/nss/lib/ckfw/builtins/certdata.txt).

The certificate data is distributed under the Mozilla Public License 2.0:
https://www.mozilla.org/en-US/MPL/2.0/

The launcher ships it because the handheld firmware has no system certificate
store, so HTTPS requests cannot be verified without it. The bundle is used only
for outbound downloads; it grants no authority to the certificates beyond the
normal TLS trust model.
